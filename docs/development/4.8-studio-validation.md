# Design studio validation — 7 November 2026

Scope: additions on `feature/jarvis-4.8-design-studio`, PR #46. The complete
OMEGA specification is not implemented or claimed complete by this change.
No release/version bump or updater promotion is included.

## Implemented

- Measured furniture inspector uses native object IDs and atomic model commands;
  validates name, positions, dimensions and angles before submitting. Confirmed
  save/ACK precedes success; native history supports undo/redo.
- Explicit top/observer camera controls.
- Local SVG export of measured rooms, walls and rotated furniture footprints,
  escaped names and a view box covering rotated/outlying objects. Multiple
  floors project into the same plane; this is not a photoreal render.
- Lists up to 50 existing project snapshots; restores an exact stored revision
  via the same acknowledged UI queue, retaining the replaced current project.
  Revision lookup accepts only positive integers, not filesystem paths.
- Shared completion for concurrent saves. A serialization comparison preserves
  the dirty flag if a manual edit occurred during the disk/network operation.
  Autosave finishes before the next queued model mutation.
- Load the stored project before asking to replace an existing drawing.
- Local editor shell styling, accessible form labels/focus and reduced motion.
- Restored browser error assertions accidentally swallowed by literal `\n`
  sequences inside a comment; removed the same text artifact from the HTML.
